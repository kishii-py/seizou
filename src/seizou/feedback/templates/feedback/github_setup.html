取得の手順

GitHub の画面のボタンの字は英語のまま「」で書きます。上から順に進めれば、トークンが取れます。

  1. GitHub の口座を用意する

    口座が無ければ github.com で作ります。会社の人の個人の口座でなく、フィードバック専用の口座 (例 会社名-seizou) を勧めます。この口座の鍵が漏れても、Issue を書く以外の害が出ないようにするためです。

    {# 絵は本体が足す: static/feedback/github/*.png #}

  2. トークンを作る (classic)

    右上の自分の絵 → 「Settings」 → 左の一番下の「Developer settings」 → 「Personal access tokens」 → 「Tokens (classic)」 → 「Generate new token」 → 「Generate new token (classic)」と進みます。

    「Note」に seizou と書き、「Expiration」(期限) は 90 日などを選びます。期限が切れたら、もう一度作ります。

    「Select scopes」で「public_repo」だけに印を付けます。送り先が非公開のリポジトリのときは「repo」に印を付けます。

    一番下の「Generate token」を押し、出た ghp_ で始まる字を 1 回だけ写します。その画面を閉じると、二度と見られません。

    fine-grained のトークンは、ほかの人のリポジトリに書けないので使いません。

    {# 絵は本体が足す: static/feedback/github/*.png #}

  3. 貼って「つなぐ」を押す

    写した字を下の「トークン」の欄に貼り、送り先を確かめて「つなぐ」を押します。上の「今の状態」に口座の名前が出れば完了です。トークンはこの会社の .env にだけ置き、画面にも記録にも AI にも出ません。

    {# 絵は本体が足す: static/feedback/github/*.png #}

  4. 送り方

    下書きの詳細で、世話役が「確認済みにする」を押してから「GitHub に送る」を押します。Issue の URL が詳細に残ります。画面の絵は GitHub の Issue に手で付けます。GitHub で Issue が閉じたら、一覧の「GitHub の状態を取り込む」で直したになります。

    {# 絵は本体が足す: static/feedback/github/*.png #}

  5. やめ方

    上の「外す」で .env から消し、GitHub の側でも、そのトークンを「Delete」で無効にします。
