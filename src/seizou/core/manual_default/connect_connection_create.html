取引先との接続の新規登録

取引先・向き・受け口の URL・鍵の置き場の名前を入れて保存する画面です。鍵の値はここに入れず、.env に置きます。

  • 使う人: 総務
  • いつ: 新しい取引先とつなぐとき
  • 何のために: 受け口と鍵の置き場の名前を登録する
  • 次にすること: .env に鍵を置き、詳細で済みを確かめる

できること

  • 「取引先」を選び、「向き」で送る相手か受ける相手かを選ぶ。両方の向きでつなぐときは 2 行に分けて登録する。
  • 送る向きのときだけ、「受け口の URL」を入れる。
  • 「鍵の置き場の名前」に、鍵の値を入れる環境変数の名前を入れる。
  • 「自社の連絡先のメールアドレス」を入れると、この取引先から会話が届いたとき、そのアドレスへメールで知らせる (送る向きか受ける向きのどちらか 1 行に入れればよい)。
  • 「保存」で登録する。「キャンセル」で保存せずに戻る。

注意

  • R12 受け口は、登録した取引先からの、署名の合う物だけを受ける。
