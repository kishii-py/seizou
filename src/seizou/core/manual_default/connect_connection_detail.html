取引先との接続の詳細

取引先との受け口と鍵の置き場の名前を見る画面です。鍵の値は画面に出さず、置いてあるか (済み / まだ) だけを出します。

  • 使う人: 総務
  • いつ: 鍵の設定が済んでいるかを確かめるとき
  • 何のために: 受け口と鍵の置き場の名前と、済みかまだかを見る
  • 次にすること: 「編集」へ

できること

  • 「鍵の設定」の節で、鍵の値が .env に置いてあるかを見る。
  • 「鍵の設定」の「鍵の指紋」を、相手の会社のつながりの詳細の字と読み合わせる (同じなら鍵の値が同じ)。
  • 「編集」で受け口の URL や鍵の置き場の名前を直す。
  • 「一覧に戻る」で取引先との接続へ戻る。

基本情報

「取引先」「向き」「受け口の URL」「鍵の置き場の名前」「自社の連絡先のメールアドレス」を出します。鍵の値そのものは出しません。

注意

  • R12 受け口は、登録した取引先からの、署名の合う物だけを受ける。
