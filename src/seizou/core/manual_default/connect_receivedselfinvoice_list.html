受けた仕入明細

得意先 (seizou どうし) が、受け入れた数と金額と受領日をまとめて送ってきた仕入明細の一覧です。得意先は受け取った物の記録から仕入明細を作り、自社は明細ごとに承諾か提案か確認できないかを答えます。左のメニューの「受信した注文」の次から開きます。

  • 使う人: 経理・営業
  • いつ: 得意先 (seizou どうし) から仕入明細が届いたとき
  • 何のために: 得意先が受け取った数と金額を確かめて答える
  • 次にすること: 行から詳細へ移り「答える」

できること

  • 「届いた日時」「得意先」「仕入明細番号」「締め期間の終わり」「支払期日」「合計」「状態」「版」を見る。
  • 「未回答」「確かめ中」のタブで、まだ答えていない物と、提案か確認できない明細がある物だけにする。
  • 行を押すと受けた仕入明細の詳細へ移る。「CSV」で書き出す。
