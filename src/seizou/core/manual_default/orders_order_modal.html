受注の小窓

受注の要点を見るだけの小窓です。受注の一覧の行の右にある目の印「要点を見る」から開き、画面を移らずに中身を確かめられます。詳細へも移れます。

  • 使う人: 営業・生産管理
  • いつ: 受注の一覧で行の中身を画面を移らずに確かめたいとき
  • 何のために: 得意先・日付・状態・明細の先頭の数行・合計を見る
  • 次にすること: 要れば「詳細を見る」で受注の詳細へ

できること

  • 「受注番号」「得意先」「受注日」「得意先の注文番号」などの項目を見る。状態は題の横の印で見る。
  • 「明細」で、先頭の数行 (行番号・部品・数量・金額・納期・残) と、明細の合計を見る。行が多いときは詳細で残りを見る。金額の閲覧が無い人には金額が出ない。
  • 「詳細を見る」で受注の詳細へ移り、「閉じる」で小窓を閉じる。編集の権限があれば「編集」で受注の編集へ移る。
