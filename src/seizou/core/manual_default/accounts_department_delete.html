部署の削除

所属する人がいない部署を消す画面です。所属する人がいる部署は、先にアカウント管理でその人の「部署」のチェックを外します。

  • 使う人: 総務
  • いつ: 使わなくなった部署を消すとき
  • 何のために: 所属する人がいない部署を一覧から消す
  • 次にすること: 所属する人がいれば、先にアカウント管理でその人の部署のチェックを外す

できること

  • 部署の詳細の「⋯」の「削除」か、部署の編集の「削除」から開く。
  • 所属する人がいる部署は削除できない。そのときは「削除」が出ず、黄の知らせと、所属する人のログイン ID と「アカウント管理」が出る。ログイン ID を押すと、その人のアカウントの編集へ移る。
  • 「削除」で消す。「キャンセル」で消さずに戻る。
