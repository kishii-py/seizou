不良の区分の新規登録

不良の区分の名前と並び順を登録する画面です。前後の空白を除いて同じ名前は、2 つ作れません。

  • 使う人: 品質・生産管理
  • いつ: 新しい種類の不良を分けて数えたいとき
  • 何のために: 実績の不良を区分ごとに数えられるようにする
  • 次にすること: 実績の入力で不良を区分ごとの行で入れる

できること

  • 「名前」「並び順」「備考」を入れる。並び順の小さい区分から、実績の入力の候補に並ぶ。
  • 前後の空白を除いて同じ名前の区分があると、赤の知らせが出て登録できない。集計の行が分かれないように、今の区分を使うか、別の名前にする。
  • 「保存」で区分を足す。「キャンセル」で保存せずに戻る。
