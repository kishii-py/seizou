標準の工程の追加

部品の標準の工程の並びに、工程の一覧にある工程を足す画面です。標準の工程は、指示書の発行で工程を選ばないときに写す工程の並びです。

  • 使う人: 生産管理
  • いつ: 部品を新しく登録したときと、作り方の工程が変わったとき
  • 何のために: 部品の標準の工程の並びに工程を足す
  • 次にすること: 部品の詳細の標準の工程のタブで順を確かめる

できること

  • 部品の詳細の標準の工程のタブの「工程を足す」から開く。
  • 「足す工程」で足す工程に印を付ける。いくつでも選べる。出るのは使用中で、まだ並びに無い工程だけ。
  • 選んだ工程は、工程の並び順のまま並びの最後に入る。順は行の「順を直す」で変える。
  • 「保存」で足すと小窓が閉じ、タブに行が並ぶ。
