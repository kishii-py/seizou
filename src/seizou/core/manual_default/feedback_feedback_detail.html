フィードバックの詳細

下書きの内容・会話の記録・GitHub の Issue に写す文を見る画面です。世話役は状態を確認済みと送ったに進めます。

  • 使う人: 全員
  • いつ: 下書きの内容と状態を確かめるとき
  • 何のために: 会話の記録と Issue の文を見る
  • 次にすること: 世話役は「確認済みにする」、GitHub に写したら「送ったにする」

できること

  • 題の下の「この件の進み具合」で、書いた・確認済み・GitHub に送った・直したのどこまで進んだかを見る (見送った件は最後が赤の「見送った」)。段の下に日時や Issue の番号が出る。
  • 「会話の記録」で AI の聞き取りの往復を見て、「Issue の文」で GitHub の Issue に写す文を見る (取引先の名前と金額らしい数は伏せてある)。
  • 世話役は「確認済みにする」で確認済みにし、GitHub とつないであれば「GitHub に送る」で Issue にする (送る前に、Issue の文の伏せ字のうち外に出してよい数だけを戻せる)。Issue の URL が残り、状態は送ったになる。つないでいなければ「GitHub とつなぐ」から始めるか、GitHub に写してから「送ったにする」を押す。
  • 「返事」で、作者が Issue に書いた返事を読む。送った件に返事を書くと、世話役が伏せ字を確かめてから GitHub に送る。
  • GitHub で対応しないとして閉じられた件は「見送った」になり、書いた人に「見送りになりました」の知らせが 1 回出る。直った版がまだこの会社に入っていない件は「送った」のままで、世話役に「直る版」が出る。版を入れた後の「GitHub の状態を取り込む」で「直した」になる。
  • 下書きのうちは「下書きの削除」で消せる。確認済みと送った物は消せない。

基本情報

下書きの項目と「状態」を出します。状態は「下書き」から「確認済み」、「送った」と進みます。
