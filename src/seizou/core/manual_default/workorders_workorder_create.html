指示書を発行する

受注の明細と数量を選んで指示書を発行する画面です。工程を選ばなければ、部品の標準の工程の並びを写します。

  • 使う人: 生産管理
  • いつ: 注文残を見て作ると決めたとき
  • 何のために: 製造部に生産を依頼する (数量と工程の並び)
  • 次にすること: 製造が指示書を受ける

できること

  • 「受注の明細」を選び、「数量」を入れる。
  • 「工程」を選ぶ。選ばなければ、部品の標準の工程の並びを写す。
  • 受注の詳細の明細の行の「指示書を発行する」から開くと、受注の明細が入っている。
  • 「保存」で発行する。「キャンセル」で保存せずに戻る。

注意

  • R06 指示書の数量の合計が、受注の明細の数を超えたら、黄の知らせと「このまま保存」のボタンが出ます。
  • R05 取消した受注には、出荷も指示書も作れない。
