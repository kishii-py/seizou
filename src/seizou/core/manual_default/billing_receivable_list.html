売掛の残

得意先ごとに、発行の請求書の合計と入金の合計と調整の合計、残を並べる一覧です。残は、請求の合計から入金の合計を引き、調整の合計を足した金額です。発行の請求書のある取引先だけが並びます。読むだけの一覧です。

  • 使う人: 経理
  • いつ: 得意先から残を問われたとき・月末に入金を確かめるとき
  • 何のために: 得意先ごとに請求・入金・調整の合計と残を並べる
  • 次にすること: 行から得意先の台帳へ。CSV で書き出す

できること

  • 「取引先コード」「名前」「締日」「請求の合計」「入金の合計」「調整の合計」「残」を見る。マイナスの金額は赤い字で出る。一番下の行に、4 つの金額の合計が出る。
  • 「絞り込み」の枠の「キーワード」に取引先コードか名前を入れて探す。「残のある得意先だけ」にチェックを入れて、残が 0 の得意先を外す。
  • 「残」の見出しを押して、残の多い順か少ない順に並べ替える。
  • 行を押すと得意先の売掛の台帳へ移る。「CSV」で書き出す。
  • 金額の閲覧が無い人には、金額の 4 つの列が一覧にも CSV にも出ない。
