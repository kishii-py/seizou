はじめに

この説明書は、画面ごとの使い方の標準の組です。画面ごとの使い方を、画面の目録の順に並べています。

開き方

  • 上の帯の「使い方」で、この説明書の全部を目次つきで開きます。
  • 画面の題の横の「?」を押すと、その画面の説明が小窓に出ます。ダッシュボードの節と、詳細の画面のタブの「?」は、その枠の説明だけを出します。
  • 使い方のページの「印刷用を開く」で印刷用の 1 枚を、「PDF」で冊子を開きます。

AI チャット

画面の右下の AI チャットの窓は、AI の鍵を置いた会社だけで使えます。画面の目録に無いので、画面ごとの説明はありません。

自社の説明書

自社に合わせるときは、会社の置き場の manual/ にあるその画面のファイルを編集するか、Claude Code で /seizou:manual を打って書き直します。部署と権限によって、出ない画面やボタンがあります。単価と金額の列と項目は、金額の閲覧の権限がある人にだけ出ます。

入力の画面

入力の画面では、画面の下の「キャンセル」と保存のボタンの行が窓の下の端に付いていて、下まで送らなくても押せます。欄に字を入れると、その行の左に「保存していない変更があります」と出ます。入れた値を捨てるときは「キャンセル」で画面を離れます。小窓の入力には出ません。

一覧の画面

絞り込みの枠で選んだ条件は、枠の下に × の付いた小さなボタンで並びます。× を押すとその条件だけを外し、右端の「絞りを外す」で枠の条件を全部外します (「キーワード」の字は残ります)。条件に合う物が無いときは、効いている条件を書いた 1 文と「すべて外す」のボタンが出ます。

詳細の画面

詳細の画面は、題の上のパンくず (一覧の名前 › 番号) の一覧の名前を押すと一覧へ戻ります。右のボタンは、主のボタン (「編集」など) が右端に 1 つで、取消と削除は「⋯」のメニューの最後にあります。受注と発注の「流れ」は、出来事の種類を絵記号で示し、番号の字はいつも下線の link で、人の記録がある出来事には誰が、受注の登録にはどの入口 (seizou で直接・読み取り・手入力) から入ったかを小さい字で添えます。
