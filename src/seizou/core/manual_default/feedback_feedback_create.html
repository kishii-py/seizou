フィードバックを送る

今の画面で困ったこと・直してほしいこと・おかしい動きを、種類・画面・題・困りごとの形で下書きにする画面です。下書きは会社の中に残ります。

  • 使う人: 全員
  • いつ: 画面で困ったとき・直してほしいとき・おかしい動きを見つけたとき
  • 何のために: 困りごと・要望・不具合を下書きにして会社の中に残す
  • 次にすること: 詳細で内容を確かめる。世話役が確認済みにして GitHub に写す

できること

  • 「種類」を「使い方」「自社の作業」「皆の要望」「不具合」から選ぶ。
  • 「画面」「題」「困りごと」を入れ、「場面」と「望む形」に困った時の様子と、どうなってほしいかを書く。
  • 「影響する画面」に、ほかに関わる画面の URL の名前を空白で区切って書く。
  • 「保存」で下書きにする。「キャンセル」で保存せずに戻る。
