発注の新規登録

協力企業と明細を入れて保存すると発注の記録ができ、つながりのある相手へ同時に注文を送る画面です。

  • 使う人: 生産管理
  • いつ: 協力企業に出すと決めたとき
  • 何のために: 協力企業に注文を送る
  • 次にすること: 相手の届いた注文に届く。物が届いたら受入

できること

  • 「取引先」「発注日」「備考」を入れる。
  • 「明細」の行に「部品」「数量」「単価」「納期」を入れ、「行を足す」で行を増やす。
  • 受注の詳細の明細の行の「発注する」からも開ける。
  • 「保存」で発注を作り、seizou どうしでつながった相手には同時に注文を送る。「キャンセル」で保存せずに戻る。
