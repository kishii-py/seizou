実績の編集

入れた実績の良品の数・不良の数・完了の印・日時・備考を直す画面です。工程は直せません。別の工程に入れた実績は消して入れ直します。直しても在庫は変わりません。

  • 使う人: 製造・生産管理
  • いつ: 入れた実績の数や完了の印を間違えたとき
  • 何のために: 実績を直す
  • 次にすること: 実績の一覧で確かめる

できること

  • 実績の一覧の行の ⋮ か右クリックの「編集」から開く。
  • 「実績の数」「不良の数」「日時」「備考」を直す。間違えて付けた「この工程を完了にする」は外して保存する。
  • 作業した人の「社員番号」か「社員の一覧に居ない人の名前」を直す。消した社員の名前と番号を写した実績では、この 2 つの欄は出ない。
  • 「実績を直す」で直して実績の一覧へ戻る。「削除」で、この実績を消す確かめへ進む。

注意

  • R07 進捗の実績の数が、その工程の予定の数を超えたら、黄の知らせと「このまま保存」のボタンが出ます。比べるのは、直す前のこの実績の数を除いた合計に、直した数を足した数です。
  • R02 数量と単価は 0 より大きい (受注の明細の数量と単価、出荷・指示書の数。実績は良品の数と不良の数がどちらも 0 以上で、合わせて 0 より大きい)。
