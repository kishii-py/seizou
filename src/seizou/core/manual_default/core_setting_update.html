設定の変更

会社の選べる設定を 1 つ変える画面です。保存した値は導入の時に決めた値より優先され、「導入の時の値に戻す」で導入の時に決めた値に戻ります。

  • 使う人: アカウント管理の担当者
  • いつ: 会社の動きを変えると決めたとき
  • 何のために: 答えの YAML を直さずに設定を変える
  • 次にすること: 設定の画面の「どこで決めたか」が「この画面で変えた」になった事を見る

できること

  • 設定の画面の行の「編集」から開く。欄の名前に、その設定が見る決まりの番号が添えてある。
  • 値を選ぶか入れて「保存」を押す。「キャンセル」で変えずに戻る。
  • 画面で保存した値は、「導入の時の値に戻す」で導入の時に決めた値に戻る。
  • 保存した後は、設定の画面で「どこで決めたか」を確かめる。
