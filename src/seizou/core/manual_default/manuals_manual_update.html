マニュアルの編集

マニュアルの本文を Markdown の字で書く画面です。上の道具の列で部品を差し込み、「プレビュー」で見た目を確かめます。

  • 使う人: 全員
  • いつ: 手順が変わったとき
  • 何のために: 本文を書く
  • 次にすること: プレビューで確かめて保存 (大きく直すなら「新しい版として保存」)

できること

  • 「題」「形式」「置き場」と「本文 (Markdown)」を直す。
  • 上の道具の列の「見出し」「箇条書き」「チェック項目」「表」などで、本文に部品を差し込む。
  • 「紐付け (部品)」か「紐付け (取引先)」で、部品か取引先の 1 件に紐付ける。
  • 「プレビュー」で見た目を確かめてから保存する。大きく直すときは「新しい版として保存」を押す。
