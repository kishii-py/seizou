部品マスターの CSV 取り込み

CSV のファイルから部品をまとめて登録し、同じ自社品番の行は更新する画面です。

  • 使う人: 生産管理・総務
  • いつ: 立ち上げのときと、部品をまとめて足すとき
  • 何のために: CSV から部品をまとめて登録・更新する
  • 次にすること: 部品マスターで確かめる

できること

  • 「見本の CSV をダウンロード」で、列の見出しの見本を取る。
  • 「CSV のファイル」と「文字コード」を選ぶ。
  • 「取り込む」で CSV の行を取り込む。同じ自社品番の行は更新する。
  • 標準単価が 0 以下の行と、単位の一覧に無い単位の行は、黄の知らせで並ぶ (入れられる。直すのは部品の編集で)。
  • 「一覧に戻る」で部品マスターへ戻る。
