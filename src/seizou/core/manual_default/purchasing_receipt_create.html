受入の新規登録

発注の明細を字で探して選び、受入日と数量を入れて保存する画面です。受け入れた数は在庫の入庫になります。

  • 使う人: 生産管理
  • いつ: 協力企業から物が届いたとき
  • 何のために: 発注の明細ごとに受け入れた日と数を記録する (在庫の入庫になる)
  • 次にすること: 受入の一覧で支払の見込みを見る

できること

  • 「発注の明細」を字で探して選び、「受入日」「数量」「備考」を入れる。
  • 発注の詳細の「受入を登録」から開くと、明細と残の数が入っている。
  • 「保存」で受入を記録する。「キャンセル」で保存せずに戻る。
  • 保存した数は在庫の入庫になり、受入の一覧の支払の見込みに入る。
