アカウント管理

アカウントの一覧です。ログイン ID で絞り込み、行を押すと編集へ移ります。発行は右上の「新規登録」からです。

  • 使う人: 総務
  • いつ: 人が入ったときと辞めたとき
  • 何のために: アカウントと部署と権限を持つ
  • 次にすること: 右上の「新規登録」で発行、行から編集

できること

  • 「ログイン ID」「部署」「権限」「状態」「最終ログイン」を見る。
  • 「キーワード」でログイン ID を探し、「絞り込み」を押す。
  • 「新規登録」でアカウントを発行し、「部署」で部署の一覧へ移る。
  • 「削除済みも表示」で、削除したアカウントも並べる。行を押すと編集へ移る。
