GitHub とつなぐ

フィードバックを GitHub の Issue に直接送るための設定の画面です。上から順に、今の状態・トークンの取得の手順・入力の形が並びます。使うのは世話役 (アカウント管理の担当者) だけです。

  • 使う人: 世話役 (アカウント管理の担当者)
  • いつ: フィードバックを GitHub の Issue に直接送れるようにするとき
  • 何のために: GitHub の口座のトークンを置き、送り先を決める
  • 次にすること: 確認済みの下書きの詳細で「GitHub に送る」

できること

  • 「GitHub でログインしてつなぐ」を押し、出た 8 文字の符号を GitHub の画面に打って「Authorize」を押す。トークンを手で作らなくてよい。
  • 「トークンを貼ってつなぐ (別の方法)」のとおりに、GitHub でトークンを作る。会社の人の個人の口座でなく、フィードバック専用の口座を勧める。
  • 「トークン」の欄に貼り、「送り先のリポジトリ (owner/name)」を確かめて「つなぐ」を押す。「今の状態」に口座の名前が出れば完了。
  • トークンは会社の .env にだけ置く。画面にも記録にも二度と出ない。
  • 「外す」で .env から消す。GitHub の側でも、そのトークンを「Delete」で無効にする。GitHub でログインしてつないだ物をやめるときは、GitHub の「Authorized OAuth Apps」で「Revoke」する。
  • 画面から .env に書けない置き場では、置き場の持ち主が端末で seizou github-token を打つ。
