アカウントの発行

ログイン ID とパスワードを決め、部署と権限を付けてアカウントを発行する画面です。部署は左のメニューに出る画面と開ける画面を、権限は登録・変更・削除できるデータの種類を決めます。

  • 使う人: 総務
  • いつ: 人が入ったとき
  • 何のために: ログイン ID とパスワードを決め、部署と権限を付ける
  • 次にすること: ID とパスワードを本人に渡す

できること

  • 「ログイン ID」と「パスワード」を決める。パスワードは 8 字以上で、よくある物や数字だけの物は使えない。
  • 「部署」に印を付けると、その部署の既定の権限に印が入る。
  • 「権限」で、登録・変更・削除できるデータの種類を付ける。「マスター編集」「伝票編集」のまとめを付けると、中の種類が全部付く。
  • 「フルコントロール」を付けると、部署・編集の権限・金額の閲覧の 3 つの制限を受けず、アカウント管理と設定の変更も使える。設定の「権限の判定」を変えるのはシステム管理者だけ。
  • 「保存」で発行する。「キャンセル」で発行せずに戻る。
