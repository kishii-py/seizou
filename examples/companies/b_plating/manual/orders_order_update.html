受注の編集

受注の項目と明細を編集する画面です。出荷済みより少ない数量にすると、会社の設定に従って止めるか知らせます。

  • 使う人: 営業
  • いつ: 数量や納期が変わったとき
  • 何のために: 受注の項目と明細を直す
  • 次にすること: 受注の詳細で確かめる

できること

  • 「得意先」「受注日」「得意先の注文番号」「備考」を直す。
  • 「明細」の行の「部品」「数量」「単価の単位」「単価」「納期」を直し、「行を足す」で行を増やす。単価は「単価表から選ぶ」でも入れ直せる。
  • 行を消すときは「消す」に印を付けて保存する。金額は保存のときに計算する。
  • 「保存」で直す。「キャンセル」で直さずに戻る。

注意

  • R04 出荷済みの数より少ない数量に、受注の明細を変えたら、黄の知らせと「このまま保存」のボタンが出ます。数を確かめてから押すと保存されます。
  • R31 同じ得意先に、得意先の注文番号が同じ受注が既にあったら (取消の受注と番号の空の受注は見ない。直すときは、番号か得意先を変えたときだけ見る。全角と半角・大文字と小文字・前後の空白の違いは同じ番号と見る)、設定の「同じ得意先の注文番号の受注」に従います。「知らせる」なら黄の知らせに既にある受注の番号が出て、同じ注文書を 2 回入れていないかを確かめてから「このまま保存」を押すと保存されます。「止める」なら赤の知らせが出て保存されず、「通す」なら知らせは出ずに保存されます。
  • R02 数量と単価は 0 より大きい (受注の明細の数量と単価、出荷・指示書の数。実績は良品の数と不良の数がどちらも 0 以上で、合わせて 0 より大きい)。
