### 3. 候補の口と写す規則 (3 段目。時間があれば。落としたら要望に 1 行)

| 関数 (10.4 のまま) | 動き |
|---|---|
| `candidates(kind, query, page, *, per_page=30)` | `kind` は `"item"` か `"partner"` (それ以外は `ValueError`)。表示の字は品目「品番 品名」、取引先「コード 名前」(05 の 2 節)。照合は Python で行う: 表示の字と `query` を畳んで (`unicodedata.normalize("NFKC")` → カタカナをひらがなに → `casefold`) 空白で切った語の全部を含む行を出す。`page` が整数に読めなければ 1 (05 の 2 節の口の行)。返す物は `{"results": [{"id": …, "text": …}], "pagination": {"more": bool}}` の辞書。空の `query` は全件。母集団は数千件の前提なので、全件を読んでから Python で絞ってよい (SQL で畳めないため。案) |
