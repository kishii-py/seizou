## 作る物

置き場は core (01 の 10.3 で帳票の関数が `seizou.core.reports` にあり、05 の 6 節で「core の帳票の部品」とある)。D5 はモデルも migration も画面も作らない。外から取る物 (フォント) は版を入れた URL から取り、取った物の版と出どころを一覧のファイル (`scripts/vendor.toml`) に書く。

### 1. `src/seizou/core/reports.py` (帳票の部品)

| 公開する物 | 約束 |
|---|---|
| `render_html(template, context)` | Django のテンプレートを描いて文字列を返す。WeasyPrint に触れない |
| `render_pdf(template, context)` | WeasyPrint を関数の中で import する (module の先頭で import しない = 00 の WeasyPrint の行。pango の無い PC で Django ごと止まらないため)。import の失敗 (ImportError と、pango が無いときの OSError) は `PdfUnavailable` に包んで投げる。`render_html` の結果を WeasyPrint に渡し、PDF の bytes を返す。`presentational_hints` は使わない (渡さず既定のまま)。`url_fetcher` は下の自作の物を渡す。`base_url` は決めた仮の起点 1 つ (形は作業のときに決め、記録に書く) |
| `PdfUnavailable` | 例外の型。置き場はこの module (01 の 10.3 は置き場を書いていない。`exceptions.py` は本体の物で触らない)。画面の側はこれを捕まえて印刷用の HTML に落とす。その画面は D5 の範囲でない (05 の 6 節。出荷の画面の日に作る) |
| `url_fetcher` (自作。名前は案 `fetch_local`) | `/static/` の下は staticfiles の finders で引く (collectstatic に頼らない)。`/media/` の下は `MEDIA_ROOT` の下だけ。解決したパスがその根の下に無ければ (`..` を含む物など) 断る。それ以外の URL (`http`・`https`・`file`・`data` など) は全部断る。断るときは例外 (WeasyPrint が「取れない」と扱う形)。鍵・環境変数・ネットワークに触らない |

- module の先頭の docstring に、WeasyPrint の無い環境では画面が印刷用の HTML に落ちる約束 (05 の 6 節) と、`[pdf]` の extras の入れ方を 2〜3 行で書く。
- PDF を base64 で返さない (05 の禁じること)。

### 2. フォントの同梱 (`src/seizou/core/static/fonts/`)

- Noto Sans JP の Regular と Bold の TrueType (OFL-1.1。決め 11-01 夜「フォントは同梱しよう」)。CFF の OTF は使わない (05 の 6 節。一部のビューアで日本語が白紙になる)。
- 取りどころと版は未確認: Google Fonts の配布 (GitHub の google/fonts の `ofl/notosansjp/` の下の static の TTF) か、noto-cjk の release。版を入れた URL から Python で取り、sha256 を計算する。static の TTF の Regular と Bold が無ければ、可変の TTF 1 本で代え、記録に書く。
- `scripts/vendor.toml` に項目を 1 つ足す (名前・版 = フォントの version の文字列・URL・license OFL-1.1・sha256・置くパス)。D4 の `tests/test_build_vendor.py` がこの項目も見るので、形を合わせる。
- `OFL.txt`: OFL の全文 (フォントの配布の条件) をフォントと同じ置き場に置く。THIRD_PARTY_NOTICES への全文の写しは D1 の物なので、記録に「`scripts/vendor.toml` のフォントの項目と `static/fonts/OFL.txt` を THIRD_PARTY_NOTICES から指す」と要望を 1 行書く。
