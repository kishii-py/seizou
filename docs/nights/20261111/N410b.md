## 足した口と URL

- core:report_copy (/copies/<pk>/。core.copies.report_copy): 写しの html の字をそのまま返す (text/html; charset=utf-8)。
- core:report_copy_pdf (/copies/<pk>/pdf/。core.copies.report_copy_pdf): 写しの html から開く時に PDF を作って返す (application/pdf)。Content-Disposition は `inline; filename="<帳票の番号>-<版>.pdf"` (帳票の番号は写しの object_text、版は revision。例 IV-000001-1.pdf)。PDF を作れない置き場 (PdfUnavailable) では、写しの html の最初の `<body…>` の直後に `<p role="alert">PDF の準備がありません。写しの画面をお使いください</p>` を入れて返す (返す字だけ。表の字は変えない)。
- どちらも @login_required と、金額の閲覧の門 access.refuse_money_document(request, "<帳票の名前>の写し")。断る文は今の門の文のまま (「請求書の写しは金額が主な内容のため、…」)。部署の判定は通さない (印刷用の画面と同じ。本体から (2))。写しが無い pk は 404。表に書かない。
- module の docstring に、写しは印刷用の画面と別の口で開くこと・金額の門を通す訳 (写しは単価と金額を空にできない)・PDF は開く時に写しの html から作ること (CSS とフォントとロゴは開く時の物を読む。字と数は発行の時のまま) を書いた。
