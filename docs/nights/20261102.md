## 門の回し方

1. 差分のパス: `git diff --name-only main...office/lane/<題>` の全部が、依頼書の「触ってよい物」の「書く」の一覧の中にあること。
2. 禁止語: 差分の中身と commit の文に、一覧の語 (大文字小文字を無視) が無いこと。
3. main に `git merge --no-ff` (衝突は 5 本とも無し)。
4. `uv sync --locked` の後に `uv run pytest -q` (全部通ること。skip の数も控える)。
5. `uv run ruff check .` (lock の ruff 0.17.3。設定は pyproject.toml の `[tool.ruff]` のまま)。
6. `uv run python -m django makemigrations --check --settings=tests.settings`。
7. 全部通れば `git push origin main`。通らなければ merge を戻して push しない。

取り込みの順は D4 → D3 → D6 → D2 → D1 (D4 が pyproject.toml と試験用の settings を持つので最初)。
