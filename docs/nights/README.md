# 無人の仕事の記録 (読み方)

このフォルダには、会期中に Claude Code の無人のレーンが書いた記録と、レーンの枝を main に取り込んだ記録を置く。日付のまとめ `<日付>.md` は、本体が取り込みのたびに書いた記録で、門の回し方は [20261102.md](20261102.md) の「門の回し方」の節にある。各まとめの「取り込みの後の main」の節には、取り込みごとの main の先頭とテストの本数が並ぶ。日付のフォルダの `<日付>/<題>.md` は、レーンが自分で書いた記録 (N は夜の仕事、D は 11-02 の昼の仕事)。[20261102/briefs/](20261102/briefs/) には、昼のレーンに渡した依頼書の写し (人の名前と運用の細部を削った物) を置く。

代表の 3 件。

- 差し戻しの例: 11-02 の N23 (図面の画像と TIFF) は、ほかのレーンの CSV の取り込みと合わせると門 4 のテストが 2 本落ちたので、取り込まずに main を戻した。core の側を直した後、39 回目に取り込んだ ([20261102.md](20261102.md) の「N23」の 2 つの節)。
- 決まりを壊す確かめ: R05 (取消した受注には、出荷も指示書も作れない) の検査のうち、取消した受注の直しを断る 2 行だけを消した枝で、全体のテストのうち `tests/test_r05_cancelled_order.py` の 1 本だけが落ちた ([20261102/N6.md](20261102/N6.md))。壊した枝 `proof/break-r05` は取り込まず、公開していない。
- 初見テスト: 作者が初めて触る人の目で画面を通した 2 回目の所見と、その直しは、[20261103.md](20261103.md) の「初見テスト 2 回目」の 2 つの節にある。直す前と後を数で比べた値は、このリポジトリに無い。
