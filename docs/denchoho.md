# 電子取引のデータの保存と seizou (電子帳簿保存法)

読み手は、会社の経理と、会社のシステムを預かる人です。プログラムは書けなくてかまいません。

## この文書は何か

この文書は、seizou のどの表とファイルが電子取引のデータに当たりうるかを並べた 1 枚です。会社が、探し方・直したことと消したことの記録・控えの手順を確かめるときに使います。

どのデータが法律の保存の対象になるか、seizou の画面と CSV が法律の求める探し方に使えるかは、会社と税理士が決めます。この文書は、それを言い切りません。法律の本文と国税庁の資料は、この文書を書いた時に読んでいません (未確認)。

## 表とファイル

seizou の中で、取引の相手とやり取りしたデータとして残る物を並べます。

| 何 | 部品 | 何が残るか | どの画面で開くか |
|---|---|---|---|
| 請求書 | billing | 得意先・発行日・締め期間・小計・消費税・合計と明細。発行した時の写しを残すかは未確認 | 請求書の一覧と詳細。印刷用の画面と PDF |
| 読み取った注文書の元のファイル | intake | 置いた注文書のファイル (PDF・PNG・JPEG) と、AI が読み取った中身・注文日・金額・得意先 | 注文書の読み取りの一覧と詳細 |
| 受信した注文 | connect | 取引先の seizou から受信した注文のデータと、見張るフォルダの読み取りから入れた行 | 受信した注文の一覧と詳細 |
| 仕入明細 | purchasing | 協力企業に出した仕入明細の項目と明細 | 仕入明細の一覧と詳細 |
| 受けた仕入明細 | connect | 得意先の seizou から受けた仕入明細の項目と明細 | 受けた仕入明細の一覧と詳細 |
| 添付ファイル | attachments | 受注や請求書などの記録に付けたファイル (検査成績書・写真など) と、ファイル名・種類・大きさ・付けた人・付けた日時 | 記録の詳細の「添付ファイル」の枠と、添付ファイルの一覧 |

## 探し方

取引年月日・金額・取引先で探すときは、次の一覧の絞りを使います。CSV は、どの一覧も画面と同じ列で出ます。

- 請求書の一覧は、発行日の期間と得意先で絞れます。合計の範囲の絞りはまだありません。合計で探すときは、CSV を取り、表計算で合計の範囲を絞ってください。
- 注文書の読み取りの一覧は、注文日の期間・金額の範囲・得意先で絞れます。注文日と金額は、AI が読み取った字のままです。金額は、読み取った数量 × 単価の合計です。単価が 1 つでも読めなかった注文書は、金額が空になります。受注にした後の金額 (取引先の端数の扱いを使った金額) とは、ずれることがあります。
- 受信した注文の一覧は、受信日の期間と取引先で絞れます。

金額の閲覧の判定を on にした会社では、金額の閲覧の権限が無い人に、金額の列と金額の絞りは出ません。CSV にも金額の列は出ません。

これらの一覧と CSV が、法律の求める探し方 (取引年月日・金額・取引先) に使えるかは、会社が確かめてください。CSV を索引簿として使えるかも未確認です。

## 直したことと消したこと

受注・発注・請求書などの詳細の画面には「履歴」のタブがあります。誰が・いつ・どの項目を・前の値から後の値に直したかが残ります。作ったことと消したことも残ります。

添付ファイルを消したときは、付けていた先の記録の「履歴」のタブに「<ファイル名> を消した」の 1 行が残ります。消した人と時刻と、消したファイルの名前・種類・大きさ・付けた人が残ります。ファイルの中身は消えます。

注文書の読み取りのように「履歴」のタブを持たない記録では、直したことと消したことは画面に出ません。

この記録が、法律の求める訂正と削除の記録に使えるかは、会社が確かめてください。

## 残す期間と控え

保存の期間は、法令と会社の事情で決まります。会社が確かめてください。期間の年数を確かめた一次の資料は、この文書を書いた時にはありません (未確認)。

控えの取り方と戻し方は、`docs/operations.md` の「毎日の控え (バックアップ)」を見てください。控えには、データベースの写しと、上げたファイル (読み取った注文書の元のファイル・添付ファイルなど) の写しが入ります。

## 事務処理規程

国税庁が公開している事務処理規程の雛形への link は、この文書を書いた時に開いて中身を確かめられなかったので書きません (未確認)。会社が規程を作るときは、国税庁の電子帳簿保存法の資料を見てください。

## 仕組みの図

```
注文書のファイル (紙・FAX のスキャン・PDF)
   │ 画面で置く / 見張るフォルダに置く
   ▼
注文書の読み取り ──────────────┐ (見張るフォルダの物)
   │ 「受注登録」                    ▼
   │                          受信した注文 ◀── 取引先の seizou から受信
   │                                │ 「受け入れる」
   ▼                                ▼
 受注 ───────────────────────────────┘
   │
   ▼
 出荷 → 納品書
   │
   ▼
 請求書 → 入金

添付ファイル: 受注・請求書などの記録に付ける。消すと付けた先の「履歴」に 1 行残る。
変更の履歴: 受注・発注・請求書などの詳細の「履歴」のタブ。
```

## 限り

- seizou にはメールを受ける仕組みがありません。メールで受けた注文書は、ファイルを画面で置くか、見張るフォルダに置きます。
- 見張るフォルダは、紙や FAX をスキャンした注文書も受けます (`docs/intake-watch.md`)。電子取引のデータと紙をスキャンしたデータは、同じ一覧に並びます。どちらに当たるかは、会社が確かめてください。
- CSV を索引簿として使えるかは未確認です。
- 会社どうしの会話に付けたファイルは、金額の閲覧の権限が無い人にも開けます。金額の閲覧の判定を on にした会社で、金額の閲覧の権限で開ける人を絞るのは、請求書・入金・発注・仕入明細・受けた仕入明細に付けた添付ファイルだけです。
- 売上高が一定の額以下で、税務署の求めに応じてデータを出せる会社は、探す機能が要らないという話があります。この話の条件は未確認です。
